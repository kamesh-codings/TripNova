# 🌍 TripNova — Smart AI Travel Companion & Tourist Safety System

**TripNova** is a modern, high-performance web application designed for tourist safety, smart AI trip planning, anti-scam fare estimation, multi-language speech translation, and digital emergency tourist passes.

---

## 🚀 How to Run the Project (Step-by-Step)

If you downloaded the code or cloned the GitHub repository, follow these quick steps to open and run the app on your computer:

### Prerequisites
Make sure you have **Node.js** (version 18 or higher) installed on your system:
- Download Node.js: [https://nodejs.org/](https://nodejs.org/)

---

### Step 1: Open the Project Folder in Terminal / VS Code
- **Option A (VS Code)**: Open VS Code $\rightarrow$ `File` $\rightarrow$ `Open Folder...` $\rightarrow$ select the `TripNova` folder. Open the terminal with `` Ctrl + ` `` (backtick) or `Terminal -> New Terminal`.
- **Option B (Command Prompt / PowerShell / Terminal)**:
  ```bash
  cd path/to/TripNova
  ```

---

### Step 2: Install Dependencies
Run the following command in the terminal to install all required packages:

```bash
npm install
```

---

### Step 3: Start the Local Development Server
Run the dev command:

```bash
npm run dev
```

---

### Step 4: Open in Your Browser
Once the terminal displays:
```
  VITE v6.x.x  ready in xxx ms

  ➜  Local:   http://localhost:5173/
```

- Hold `Ctrl` and click the link `http://localhost:5173/`, or open your browser (Chrome / Edge / Brave / Safari) and visit:
  👉 **`http://localhost:5173/`**

---

## 🛠️ Project Features

- 🗺️ **Smart Tourist Dashboard**: Live destination weather, SOS trigger, top travel picks, verified safety places, and local guides.
- 🗣️ **26-Language Smart Voice & Text Translator**: Real-time translation across 10 Indian and 16 Global languages with Speech-to-Text and crystal-clear audio broadcast.
- 📻 **Two-Way Walkie-Talkie Mode**: Speak-and-translate live conversation between tourist and local resident.
- 🛡️ **Anti-Scam Fare Guard**: Distance, official government rates vs. quoted price scam meter, and bargaining phrases.
- 🪪 **Digital Emergency Tourist Pass**: Vital health data, blood group, emergency contacts, and one-tap emergency audio broadcasting.
- 📅 **AI Smart Trip Planner**: Budget estimator, duration planner, packing checklist, and customized itineraries.
- 👤 **Profile Management**: Profile creation, view & edit, and delete profile options.
